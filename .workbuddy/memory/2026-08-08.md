## AI NPC 仿真原型搭建 — 12模块完整实现

- 搭建 prototype/ 目录, 12个JS模块 + HTML + CSS
- config.js: 8阵营关系矩阵(ally/enemy/neutral/tense), 8种NPC类型(guard/mtf_private/mtf_sergeant/ci_soldier/goc_soldier/scp_173/scp_049/scp_939/zombie), 8种武器, 6波时间线
- vector2.js: 2D向量数学, 视野锥检测, DDA光线投射视线遮挡
- fsm.js: 通用有限状态机(巡逻→警觉→交战→撤退→死亡)
- pathfinding.js: A*网格寻路 + 路径简化 + 对角线穿墙检查
- mapsystem.js: BSP随机设施生成, 4区域(LCZ/HCZ/EZ/SZ), 走廊连接, 门禁, 出生点/出口
- perception.js: 视觉(视野锥+视线遮挡) + 听觉(声音事件系统)
- npc.js: NPC实体 + 8种行为模式(guard/sweep/raid/hunt_scp/scp_173/scp_049/ambush/zombie) + FSM状态逻辑 + 射击/移动/碰撞
- combatsystem.js: 子弹弹道, 伤害解算(护甲减免/SCP免疫/能量武器2x), 049复活僵尸, 伤害数字
- aisystem.js: 全NPC更新调度, 波次生成, 阵营统计
- renderer.js: Canvas渲染(地图/视野锥/NPC/子弹/HP条/状态标签/HUD)
- game.js: 主循环, 速度控制(暂停/1x/2x/4x), 显示切换, 手动生成, 事件日志
- 修复: 中立阵营不触发警觉逻辑
- 原型运行在 localhost:8080
- 下一步: 观察仿真效果, 加入可操控角色
