# SCP收容失效 HTML版 — 项目长期记忆

## 项目概况
- 类型: 基于SCP收容失效的HTML5 2D俯视角游戏
- 平台: HTML5 Canvas 2D
- 目标用户: SCP核心粉丝
- 单局时长: 25-35分钟

## 设计方向 (v0.3)
- 核心Fun Hypothesis: 「在活着的、多阵营混战的收容失效设施里扮演角色」
- 6个可选角色: D级/科学家/MTF/GOC/CI/可操作SCP
- 参考SCP:SL(战斗/收容) + RXSEND(多阵营策略)
- AI控制其他阵营NPC, 设施是自运行生态系统
- 波次增援: 0min开局→5min 079→10min CI→15min MTF→20min GOC→25min核弹
- 4区域: LCZ→HCZ→EZ→SZ, 随机生成
- 可操作SCP: 173/096/106/049, 各有完整技能体系

## 关键设计原则
- 武器对主要SCP基本无效(子弹弹开), 只有GOC能量武器和收容泡沫有效
- 弹药稀缺, 每发都是决策
- AI阵营不围绕玩家转——MTF和SCP可以自行交战
- 知识仍是核心: SCP规则、阵营关系、设施布局=生存优势
- 战斗·收容·策略三位一体: 同一目标可用多种方式达成

## 版本演进
- v0.1: 无力求生(知识对抗恐惧)
- v0.2: 有能力逃出生天(异常能力+武器)
- v0.3: 多阵营多角色(6角色+AI模拟+波次)
